# AGENTS.md

Before building or changing any UI in this repo, read DESIGN.md. It is the
binding design contract for VibeFlow: theme, tokens, typography, components,
layout, elevation, and motion. When a screen is built or changed, follow it.

If a change needs a color, size, or pattern DESIGN.md does not cover, extend
DESIGN.md in the same change instead of improvising, per its §9.
